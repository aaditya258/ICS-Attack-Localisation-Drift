# Data

The datasets are not redistributed here. Request them from their providers:

- SWaT A1 (2015) and WADI A2 (2019): iTrust, Centre for Research in Cyber Security, Singapore University of Technology and Design
- HAI 22.04: downloaded automatically by `prepare_data.py`

`prepare_data.py` converts the raw files into this folder. Set the environment variable `LENSR_DATA` to use another location.
